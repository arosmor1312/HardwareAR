# HardwareAR — página web

Web multipágina estática creada con HTML, CSS y JavaScript. Cada pestaña abre una página independiente.

## Verla en tu ordenador
1. Descomprime el archivo ZIP.
2. Abre la carpeta con Visual Studio Code.
3. Abre `index.html` en tu navegador (o utiliza la extensión Live Server).

## Publicarla con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta a la raíz del repositorio.
3. En GitHub, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera a que GitHub Pages genere el enlace.

## Personalización
Puedes editar los textos y datos de contacto en los archivos HTML. El diseño y los colores se modifican en `styles.css`.
